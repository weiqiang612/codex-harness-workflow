# Sanitized workflow evidence

This directory contains a reduced, anonymized evidence bundle derived from real use on an environmental-monitoring full-stack application.

## Contents

- [Harness tree](harness-tree.md): durable project context created before feature work.
- [Specification excerpt](task-package/spec-excerpt.md): six acceptance criteria produced for a field-measurement feature.
- [Task-list excerpt](task-package/tasks-excerpt.md): the sixteen planned documentation, implementation, and verification steps.
- [Verification summary](verification-summary.md): passed, incomplete, and unmeasured outcomes kept separate.

## Evidence boundary

The files preserve the workflow shape and verified counts while removing the original project name, machine paths, accounts, internal role codes, concrete database names, source code, and business data.

This is evidence that the workflow was exercised. It is not a runnable demo and not a benchmark. A disposable end-to-end sample project remains a separate release task.
